# 📝 AI Text Summarizer Web App

A simple AI-powered web application that summarizes long text using OpenAI's GPT model.  
Built with Python and Streamlit, this project demonstrates how to integrate LLM APIs into a real-world interactive application.

---

## ✨ Features

- ✂️ Summarizes long paragraphs into short, clear text  
- 🤖 Uses OpenAI GPT-4o mini model  
- 🌐 Simple web interface using Streamlit  
- 🔐 Secure API key handling using environment variables  
- ⚡ Fast and lightweight CLI + web version

---
